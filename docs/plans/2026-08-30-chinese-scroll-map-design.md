# 华夏博物舆图：二维手卷场景设计

## 目标

以可交互的中国画手卷替代首页 3D 地形。它不是古地图复刻，而是把真实省级边界、博物馆坐标与传统舆图的观看方式结合：轻、静、可读，有纸本与手工感。

## 视觉依据

- 《禹迹图》（1136）：借鉴方格秩序、河流优先和“山川先于装饰”的信息层级。
- 《坤舆万国全图》（1602）：借鉴多联长卷、题记与地图并置、密而不乱的版面章法。
- 《广舆图》与康熙朝省域舆图：借鉴墨线、淡彩、山形符号与纸本设色。
- 省界、地名和交互坐标继续使用项目内 GeoJSON 与现有数据，不从历史舆图推导现代疆界。

## 场景结构

1. 深色漆案作为背景，承托纸本而不抢视觉中心。
2. 画心采用横向宣纸，左右木轴明确“手卷”物性。
3. 首次进入以约 1.2 秒展卷动画出现；低动态偏好下直接展示。
4. 画心由浅方格、真实省界、主要水系、象征性山形、地名朱印、题签与收藏印组成。
5. 默认省份使用淡矿物色，悬停加深墨线，选中落朱印；博物馆用小型朱砂信标展示。

## 交互原则

- 点击省界或地名均进入省份，键盘 Enter / Space 同样可用。
- 港澳使用引线与独立的大触控热区，避免小面积边界难以点击。
- 选省后保留现有省份侧栏；点击馆点进入现有博物馆详情。
- 指针经过国土时仍显示经纬坐标。
- 移动端不要求缩放或旋转；保持“一次轻触即入卷”。

## 性能原则

- 使用原生 SVG 与 CSS，不加载 WebGL、地形纹理或 Three.js 主场景。
- 山、水、方格均为少量矢量路径；省界仅在数据加载后一次生成。
- 装饰层在窄屏自动减量，交互热区不缩小。
