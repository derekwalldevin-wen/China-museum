# 「山河入画·循迹寻珍」静态首页设计冻结

日期：2026-09-16  
阶段：高保真静态首页候选；暂不实现新开场，不发布线上

## 目标

首页首先让普通游客感到“眼前是一幅可以进入的山河图”，随后在三秒内理解三件事：可以点省份、可以按朝代找文物、可以从故事开始。真实省界、博物馆与文物数据继续承担知识导航，山水只负责气氛和空间层次。

## 方案比较

1. **山水战略舆图（采用）**：真实地图置于宣纸中央，远山、云气、岸石分布在地图外缘；深色题签栏承载搜索与筛选；朱印承担地理入口。探索感强，且能复用现有SVG点击区域。
2. **博物馆编辑画册**：大标题与精选故事占主位，地图退居次要。阅读优雅，但削弱“全国探索”这一产品独特性。
3. **重度历史游戏面板**：大量木框、金属、数值和多级菜单。氛围直接，但会让知识网站显得像策略游戏，并挤压手机空间。

## 冻结构图

- 全局：乌木案面托起暖灰宣纸，主色为松烟墨、旧纸、石青、朱砂；不用高饱和金色和厚重拟物金属。
- 顶部：左侧馆印与题名，中部搜索，右侧“九州名录 / 故事游线”；第二行是省份题签、横向年代签和类别。
- 卷面：地图占视觉中心约60%，左上写“山河入画”，背景使用原创SVG远山、云气、近岸与小亭；装饰层不拦截省界点击。
- 地图：省界采用同一墨色体系的矿物淡彩，悬停时才显朱砂描边；省级入口继续使用朱印，保留34省、港澳引线与博物馆朱印。
- 故事入口：左下纸笺以《清明上河图》为第一条可操作引子，说明“从一件文物进入一段时代”，直接进入既有故事导览。
- 手机：顶部题名压缩为单行，搜索独占第二行，筛选为两列；地图最大化，故事纸笺收成底部横条，保持44px触控入口。

## 技术与边界

- 视觉资产均为项目内原创CSS与内联SVG，不请求新图片、字体或第三方UI资源。
- 不修改GeoJSON、地图坐标、标签中心、港澳引线、筛选URL、故事路由、文物图片与溯源模型。
- 原“一纸启封”在本阶段暂停触发，使预览直接进入静态首页；代码保留，待静态视觉确认后按新画面重做2.8秒连续开场。
- 继续守卫390px故宫首屏两张图片，并运行地图点击、筛选URL和桌面/手机视觉回归。
