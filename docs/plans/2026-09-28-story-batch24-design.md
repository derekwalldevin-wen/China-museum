# 第二十四批秦陵双件故事设计

## 路线选择

在薄证据大批量填空、继续停留在既有已完成故事、优先逐件官方档案三条路径中选择第三条。秦陵博物院公开铜车马坑发现档案、两乘工艺说明、一号车2021—2024年保养记录；跪射俑有逐件形制卡、二号坑发掘概述和彩绘保护展文。信息足以写成两篇可信的四节故事。甘肃与殷墟待馆方逐件记录更可核时再推进，未从总目标移除。

## 叙事与证据边界

- 铜车马：1980年12月两乘同坑；区分“前立车/后安车”与展览的1/2比例、整组3500余零件；旧修复史按一/二号车分别写，现代2021—2024年分析及维护只属于一号车。院方一篇新闻开头误写1978，与逐坑/专题1980冲突，明示以逐坑记录为准。
- 跪射俑：本站是类型条目，不指定某个编目号；单件藏品卡提供姿态和二号坑位置，1998年8件彩绘跪射俑是群体研究，不等于当前图片中的个体。绿脸俑1999年的“得”字铭和保护工单不并入。
- 两者联系“彩绘如何随埋藏与出土改变”，不暗示同匠同模或共同埋在一坑。图片登记、AI标签、URL、筛选和阅读位置不改。
