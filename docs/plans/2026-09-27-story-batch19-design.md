# 第十九批：五件跨地区藏品故事设计

## 决策

在“继续只修既有样板”“一次铺开八件”“先做五件证据较足的缺口藏品”三种路径中，选第三种：它直接缩小121件未覆盖缺口，又允许逐段核证。沿用现有分批故事 JSON、轻量题签/路由、四章三细节和来源面板；不调整组件、地图、URL、图像和授权模型。

## 五件与叙事问题

1. 辽宁《虢国夫人游春图》宋摹本：原作、宋摹、20世纪摹本与数字展示怎样分层？宋徽宗亲摹和画中人物识别只作展览归属/研究意见。
2. 河北错金银四龙四凤铜方案座：仅存案座如何认识原案、四鹿四龙四凤与斗拱？分清官方展陈、工艺推断与缺失的木案面。
3. 定州龙螭衔环谷纹青玉璧：墓中位置、龙螭与谷纹能说明什么？不从璧的形制直接推定一次具体祭天仪式。
4. 南京西汉金兽：窖藏组合如何限制“镇库”“镇席”等用途猜测？“黄六”释读、动物辨认和埋藏者身份分别标研究解释/未知。
5. 浙江河姆渡双鸟朝阳纹牙雕：可观察的双鸟、同心圆和火焰状纹，与太阳崇拜解释、器物实际用途分开。

## 数据与验证

新增 `stories-batch19.json`，每篇四章、至少三细节、一道亲子问题及两条不暗示直接传承的关联比较。旧简述若超过证据边界，同步修正 `museums.ts`；完整故事继续按需加载，轻量题签接 `story-routes.ts` 与 `story-teaser-hooks.ts`。本批文字来源只代表内容依据，图像登记/AI状态/授权不触碰。逐字段测试约束新故事存在、旧错误移除、引用可解析、关联目标有效；生产构建后做桌面及390px手机直接URL、来源链接、关联跳转/返回、横向溢出与图片标识验收。目标未达全馆及约300件前不发布。

## 风险

部分省文物局旧页只可检索片段；记录真实 `retrieval` 等级，不写成全文核读。候选原始发掘/逐件修复档案如不可获取，在 `uncertainty` 中保留空白；不因为报告书目存在就写逐件工作过程。
