# 「山河入画·循迹寻珍」网页动效设计

日期：2026-09-16  
状态：方向冻结，进入本地实现；不发布线上。

## 选型

### 采用：叙事型墨卷

用2.8秒完成一次连续镜头：宣纸呼吸、墨山显影、器物负形成为路线线索、朱印落款、真实地图接管。开场不是独立广告片，而是首页舆图的前一帧；结束后题签、筛选与故事笺沿同一视觉轴出现。

### 未采用：强戏剧性镜头

更强的推拉、墨浪和多次震动更像游戏宣传片，会增加眩晕、GPU占用并削弱文物内容的可信气质。

### 未采用：1.2秒轻显影

性能最好，但不足以建立“山河中寻珍”的叙事期待，也无法承接用户希望增强探索吸引力的目标。

## 2.8秒分镜

1. **0–350ms · 一纸初展**：深色漆案中纸卷展开，纤维与淡水痕出现。
2. **350–1100ms · 山河醒来**：远山、中景和河道依次显影，运动以低频横向扩散为主。
3. **1100–1800ms · 循迹见珍**：玉璧、瓷瓶、青铜器负形在山河间短暂出现，以路径点连接，不伪作文物原件。
4. **1800–2150ms · 朱印定卷**：印章一次落下，只有轻微尺度回弹，不使用夸张震屏。
5. **2150–2800ms · 舆图接管**：纸卷和遮罩同步淡出，底层真实省界、题签和故事笺从相同位置接管。

## 页面反馈

- 省域：悬停时只提升墨色和内阴影，点击用一次短促“蘸墨”反馈；不让省份漂浮。
- 朱印：hover/focus微抬，active回落，保持44px触控命中区。
- 年代签：活动下划线像墨迹横扫，切换时不移动布局。
- 故事引路笺：纸边轻抬、箭头沿阅读方向移动；不持续呼吸闪烁。
- 搜索与题签：focus只提高边界与局部光泽，不加入发光霓虹。

## 性能与无障碍

- 最终采用原生CSS/内联SVG与小型按需动效控制器，不加载Three.js、Canvas、纹理、模型或额外字体。软件WebGL冷启动无法稳定满足500ms准备截止，因此舍弃原单平面方案。
- 500ms准备截止、3.3秒墙钟上限、随时跳过、Escape、页面隐藏与业务导航退出全部保留。
- Save-Data、2G/3G、低资源、低电量、减少动态设备使用静态替代；业务深链接完全绕过开场。
- 开场退出时卸载动效DOM、取消requestAnimationFrame并释放监听器；无GPU上下文需要释放。
- 390px馆内直达仍不得请求开场块，首屏保持2张图片。

## 验收

- 桌面5帧、390px 4帧分镜截图；结尾与真实地图无白闪和黑闪。
- 跳过退出小于100ms，退出后canvas为0。
- 低性能静态替代不请求Three.js块。
- 地图34省、港澳引线、筛选、URL、详情返回、故事与图片调度回归全部通过。
