# 第十八批故事设计：同一件文物的多层时间

本批比较三个执行选项：仅修正旧卡片最快，但不能推进全馆故事覆盖；立刻扩充新馆藏有助于接近300件，却须同步完成单件身份与图像链；先完成三件已录但缺故事的藏品，现有馆方材料足以写出可审计的发现、制作和现代流传，是本批选择。新馆藏及图片仍为长期目标，不被本批替代。

三件以不同的问题驱动：凤首扁壶问“发现地能告诉我们什么”，把元大都院落瓷器窖藏与现代修复传说分开；《雪景寒林图》问“一幅雪景如何传到公共博物馆”，把画面、鉴藏题跋和1981年捐赠分层；太保鼎问“三字铭文能证明谁”，将器上可见文字、学者释读、梁山七器出土异说与1958年捐赠区分。每件四章依序安排器物/画面事实、制作或技法、发现/递藏研究、当代保护传播，另有三细节、思考题、两条说明比较理由的链接。

沿用分批JSON与轻量题签架构，故事正文延迟加载；不改图片注册表、AI与授权披露、URL或阅读位置组件。证据只绑定直接支持该句的馆方页。天津部分页面只能取得搜索文本，明示检索深度；不能取得的原始发掘报告、保护工单或论文全文不以二手材料冒充。验收须核对唯一ID、来源引用、四章结构、全量数据与构建，并在桌面/390px手机测直接链接、筛选参数、关联跳转、历史返回和图像请求边界。项目无Git元数据，本文件不执行提交。
