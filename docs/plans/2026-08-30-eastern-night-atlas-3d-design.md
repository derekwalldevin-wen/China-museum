# 东方夜航舆图：3D 首页成品设计

## 定位

把现有三维地形从“可操作的数据沙盘”提升为“进入中华文明展厅的夜航序章”。地图始终是唯一主角；检索、筛选、坐标和操作说明退为展签式辅助信息。整体避免游戏 HUD、泛黄仿古和高饱和科幻光效，采用当代博物馆中的东方材料语言。

## 视觉系统

- 墨夜黑 `#080a09`：场景背景与深层空间。
- 宣纸灰 `#d8cfb7`：主要文字、省界与高光。
- 漆朱红 `#a93424`：选中状态、印章和关键操作。
- 岁月金 `#b49a63`：河流、悬停、地形侧光和细线。
- 矿物青 `#657e78`：海面、远山和冷色补光。

地形采用低饱和矿物色带、宣纸粗糙度与柔和边缘羽化；海面使用墨色微光和缓慢的层叠波纹，不再出现大面积亮蓝点阵。后期只保留克制的暗角、暖色分级和细颗粒。

### 微地形层染修订

最终地形不采用戏剧化高差，而采用接近纸上浅浮雕的微地形：最高区域控制在原始沙盘视觉高度的约 12%–18%，并对极端高程做非线性压缩。山河识别主要由八级矿物色层、细金等高线、河流金线和低角度柔光完成。默认镜头进一步接近俯视画卷；只有用户旋转或进入省份时，微小起伏才被感知。周边异域地形压低为近乎平面的墨色远景，海岸不发出强烈青光。

## 信息层级

1. 中华地形与当前选中省份。
2. 省份入口、博物馆入口与选中反馈。
3. 品牌、检索、目录、筛选。
4. 坐标、画质、手势提示与装饰题记。

省份默认表现为低亮度的小型地名钉；悬停或键盘聚焦时才展开为朱印，选中后出现光晕并让其他省份退场。移动端仅显示大触控热区和小圆点，保留港澳引线，不牺牲可点击性。

## 交互与动效

- 首屏以 900–1200ms 的场景显影完成入场，不阻塞操作。
- 悬停反馈在 180ms 内完成，点击在 50ms 内产生压下反馈。
- 省份镜头沿用现有飞行逻辑，视觉上通过目标区域增亮、边界转为漆朱红完成“入卷”。
- 高性能设备保留雾、云、海面微动与后期；标准和节能档不增加几何复杂度。
- `prefers-reduced-motion`、低内存、低核心数或节流网络继续进入节能档。

## 响应式与可靠性

桌面端使用透明渐隐的上下展陈框架；移动端把筛选压缩为两行，隐藏纯装饰信息并为地图留出主视区。所有新增质感由 CSS 与程序化 shader 完成，不增加网络图片依赖。WebGL 不可用时仍进入全国目录，现有 URL 导航、搜索、港澳触控和博物馆详情逻辑保持不变。

## 验收标准

- 桌面首屏只有一个明确视觉焦点，省份标签不再形成红色噪声墙。
- 地形边缘无明显数据断崖，海面不呈现科幻点阵感。
- 390px 宽设备无横向溢出，核心地图操作与 44px 触控热区有效。
- 高、标准、低三档均可进入地图；低档不新增持续动画负担。
- TypeScript、ESLint、生产构建通过，并完成桌面与移动端截图验收。
