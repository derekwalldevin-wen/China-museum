## 美术规范

主题“一纸藏千年，启卷见万象”。页面文字：标题“华夏博物志”，副题“循一件文物，读一段故事”。文字从静态首帧即可读，不逐字打字，不伪造古人书法。

沿用当前暖纸 #efe6cf、墨色 #0d100e、朱砂 #a93424、旧金 #b49a63 与地图低饱和青绿。朱红面积≤画面3%，墨迹覆盖≤25%，主体留白≥55%。纸纹对比度低，不能有发光粒子、镜头炫光或大面积亮白闪现。

画面始终正视；纸面只有边缘光影和极轻曲度暗示，不建立立体地形。桌面横向展开，纸幅约视口宽72%、最高520px；手机纸幅宽约86%，竖向题签与一个主轮廓，辅助两轮廓仅局部显露。标题手机32–40px，副题14–16px，正文对比≥4.5:1。

文物轮廓是自行绘制的“陶瓷瓶形、玉璧环形、青铜器形”抽象品类意象，无文物名称、纹饰铭文或原作细节，不调用现有191件图片，不从AI图描出伪原作结构。装饰图层 aria-hidden。若未来改为特定文物，必须走已有证据与授权流程。

## 完整分镜（从首帧可播放时起2.8秒）

| 时间 | 视觉与运动 | 信息与交互 |
|---|---|---|
| 0.00–0.35s | 已有纸面静帧轻微显出纤维，左下墨边开始浸润；不从黑屏闪到白屏 | 标题、副题、右上“跳过开场”始终可用 |
| 0.35–1.10s | 一道不规则湿墨沿纸横向推进，边缘出现很少飞白；瓶形主轮廓以负形显现，玉璧/铜器只作侧边呼应 | 无文字解释弹出，不要求滑动 |
| 1.10–1.80s | 墨色由湿到干，轮廓保持约0.5秒；题签清晰稳定 | 用户识别“文物故事”的主题 |
| 1.80–2.10s | 自制“博物”朱印以1.03→1.00比例轻落，印边局部沁色；无镜头震动与弹跳 | 不播放自动音效 |
| 2.10–2.80s | 纸面由中缝向左右揭露底层现有地图，墨边随纸离开；底层不截屏、不重绘 | 遮罩结束后恢复原页面命中，开场彻底卸载 |

静态版使用首帧题签、纸纹、淡轮廓与已落定朱印，无渗墨、位移、缩放或淡入动画。它只作为现有首页加载阶段的静态封面；地图就绪立即撤去，不人为停留三秒。加载失败露出原有失败恢复界面。

## 触发与时限

- 仅首次首页导航、无业务query/hash、无会话已看标记且非reload/back_forward时具有自动播放资格。馆、文物、筛选、故事、分享URL完全绕过开场，连Three.js块也不加载。
- 同标签页 sessionStorage 记录 introSeen:v1；开始或跳过即记已看。存储不可用时本次运行只播一次，并通过 Navigation Timing 跳过刷新/后退；跨重新打开页面无法保证记忆，作为明确限制。
- App先挂载现有页面。首个静态页面帧后才加载开场动态模块，允许已有地图请求先发出。准备窗口≤500ms；模块或着色器没有及时就绪，静态版直接退出，不迟到补播。
- 动画最长2.8秒；从开场静态壳出现到卸载墙钟上限3.3秒。地图未就绪也必须结束，接回现有加载/失败恢复界面，禁止无限等待。
- 按跳过、Esc、页面隐藏、路由变化、系统减少动画设置改变、contextlost时立即进入退出流程，≤100ms撤去遮挡；迟到import结果只能释放，不能再次挂载。

## 技术架构

拟新增 IntroGate（轻量React控制器）、InkScrollIntro（动态Three.js渲染器）、intro-policy（纯资格判断）、intro-assets（自制静态矢量图集）。只在App现有页面外层加入可卸载装饰层，不改业务路由、history state、地图数据或图片加载器。

状态：bypass / static / preparing / playing / disposed。所有出口汇合到幂等dispose；会话标记不写进现有URL或阅读位置键。导演进度仅由performance.now驱动，rAF内部更新uniform，不逐帧setState。

使用现有Three.js依赖的WebGLRenderer、正交相机与一个屏幕平面；自制小尺寸灰度轮廓/纸纹图集、少量确定性噪声、时间控制的湿墨遮罩。优先1 draw call，不加EffectComposer、Bloom、真实流体、额外动画库或3D模型。真实地图保留为DOM/SVG，canvas只通过alpha揭露它。

DOM承担标题、说明与跳过按钮；canvas aria-hidden、pointer-events:none。按钮在独立DOM层。开场可见时若阻挡地图视觉，则底层地图区域暂设inert；不得把控制器一起inert。键盘Tab进入跳过，Enter/Space与Esc均可退出；不自动抢焦点。仅当焦点在将卸载的按钮上才把焦点放回已有主页入口，使用preventScroll。

清理：取消rAF/timer、移除监听和canvas、dispose纹理/几何/材质/renderer。StrictMode重复挂载、异步模块迟到和contextlost均不得产生二次播放或残留遮挡。Three.js网络请求已发出后无法保证取消，不伪称零传输；直达业务URL则根本不启动import。

## 资源预算与降级

| 项目 | 硬预算/策略 |
|---|---|
| 入口增量 | ≤3KiB gzip，包含门控和静态壳；业务直达不下载动态开场块 |
| 开场动态总增量 | 目标≤180KiB gzip，包含Three.js实际打包依赖、shader与图集；必须实测。超过200KiB时先缩减，仍超则自动播放保持关闭 |
| 图片/字体网络 | 开场0个额外图片请求、0字体请求；图集用自制内联矢量在内存栅格化≤512²，无远程纹理 |
| 几何与GPU | 1平面≤2三角形，draw calls≤2；不使用离屏后处理目标；自有纹理≤2MiB，渲染附件预算≤24MiB（估算，非全驱动显存测量） |
| 画布像素 | 桌面≤1.5百万像素、手机≤0.6百万像素；按总像素限额缩放，不盲从DPR；DOM字保持原生清晰 |
| 帧率 | 合格桌面目标≥50fps、合格手机≥30fps；连续10帧间隔>40ms即静态收束，不另跑耗电基准 |
| 主线程 | 不新增>50ms长任务作为验收目标；shader编译和模块解析列入trace，超标设备降级 |
| 现有网络守卫 | 390px馆内首屏仍2图/37,140 B，空闲仍仅当前馆约3KB；任何开场纹理或详情图请求均不允许 |

静态条件：prefers-reduced-motion、Save-Data、slow-2g/2g/3g、已知deviceMemory≤4GB或hardwareConcurrency≤4、已知电量≤20%且未充电、无WebGL2、初始化/模块失败。手机资源信号全缺失时保守用静态版；信号只作门控，不声称测得真实GPU能力。电量接口缺失不推断电量，拒绝/迟到结果不能阻塞阅读。

运行时网络转受限或电量进入已知低位即提前退出。无requestIdleCallback不影响开场资格；开场准备不能占用馆内provenance的调度通道。无WebGL情况下不创建重试循环。

## 验收标准

1. 固定时间截图0/350/1100/1800/2100/2800ms，桌面1440×960、手机390×844及横屏；检查纸纹、轮廓、字体、落印节奏、图层接缝和无横向溢出。截图使用测试专用时间控制，不暴露到生产URL。
2. 首次首页自动播一次；同会话刷新、前后退、业务深链接0次。跳过/Esc/隐藏/切路由任意阶段均≤100ms退出，URL、history state和阅读位置不变。
3. Save-Data、2G/3G、低资源、低电量、减少动态效果、WebGL禁用、import失败分别注入：静态可读、入口可用、无动态开场请求。WebGL禁用可在动态模块内部才检测到时允许模块加载，但不得创建循环或额外资产请求，报告区分。
4. 390px馆内直达使用CDP禁缓存守卫，首屏卡片严格2张/37,140 B，开场JS及图片0请求；不触发详情预取，现有provenance策略通过。
5. 地图34省、港澳触控、全国组合筛选、URL刷新/分享/历史、详情返回与故事阅读位置、长卷双图、隔离和授权披露沿用必要回归。
6. 前后同网络配置至少5次冷启动，分别报告中位数与范围。首页地图可交互时间相对基线增量≤150ms（与覆盖层结束时间分开计），入口CLS增量≤0.01；业务深链接时间差在测量噪声内，超预算不开自动播放。
7. 跳过按钮≥44×44 CSS px且不被安全区遮挡，文本对比≥4.5:1；键盘和屏幕阅读器可跳过，不播音、不闪烁、不朗读装饰。减少动画模式下时间轴、视差、缩放全部关闭。
8. 重复挂载/退出20次：无活跃rAF、监听器及canvas累计；资源引用回到基线，不能只据renderer.info宣称浏览器显存已归零。
9. 无头可验证流程和截图；硬件帧率、触屏感觉、移动Safari与读屏需真机抽验。无头禁GPU成绩不能替代GPU性能结论。
