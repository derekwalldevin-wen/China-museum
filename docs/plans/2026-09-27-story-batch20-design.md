# 第二十批三件旧藏品证据故事设计

现有206件藏品、90篇完整故事。此批不新增图片，不改馆藏数量，补三件有可核资料的旧藏品：《宝顶山千手观音》《莫高窟第257窟九色鹿本生》《侯马盟书》。选择依据是原始机构工程记录、逐窟目录和正式论文可公开阅读。相比继续改已覆盖样板，这能减少故事缺口；相比一次填十件，能逐段验证事实并保留争议。

沿用四章、细节卡、思考题、关联比较及逐段 `refs`。第一件以“宋代雕凿—材料层—2008勘察与2011—2015本体修复—今天怎样看修复痕迹”为线；第二件以“窟位和年代—从两端读至中央—经文与画面的区别—数字化和报告目录”为线；第三件以“秦村甲乙区—玉石片朱书—主盟人争论—1965发现、1966简报与1976整理”为线。凡资料只讲遗址整体或论文的现代解释，不把它们冒充本站单件的原始处理档案。

先修正 `museums.ts` 三条旧简介，再写 batch20 JSON；同步轻路由与题签，生成逐件载荷。数据测试覆盖引用、互链和边界；本地生产构建后验收桌面/390px手机直达、跳转、阅读位置及两图请求。图像元数据完全不动。网站最终发布仍须完成全目标，不能把本批当作交付完工。
