## 二、本轮把"来源身份"保护固定成流程

上一轮发现我改写时凭记忆重建了 source 的 URL。本轮把修复脚本改成**通用工具**并在每次改写后运行：

```
node .tmp/restore-source-identity.mjs src/data/stories-batch55.json ...
```

它对每个 source 按 id 从 `HEAD` 取回 `title / institution / url / checkedAt / retrieval / kind` 等全部字段（只保留重写的 `supports`），并在 source 数量或 id 不匹配时**直接报错退出**。本轮对 batch55/51/53 三个文件运行，全部校验通过。
