## 二、本轮做到的（第六十九、七十批共 6 篇，整篇重写）

风格锚点（改写前后各举一例）：

- **开场**
  - 前：`【器物事实】这块展厅说明牌只有两行：中文器名「彩漆木雕龙纹盖豆」……没有时代、没有出土地。`
  - 后：`一只豆，盖顶雕着龙，通身漆色发暗。盘子只写了它的名字——彩漆木雕龙纹盖豆。名字里的四个字，恰好把它的样子说完了：彩漆、带盖、豆形、雕龙。`
- **不确定**
  - 前：`本轮来源仅为展厅说明牌照片……展签未标器名、时代、出土地；本页不作推断。`
  - 后：`展签未标年代与出土地，这里也不标。`
- **关联条目**
  - 前：`与同在湖北省博物馆的彩漆木雕鸳鸯形盒比较"两件漆器的著录详略"：……比较的是同馆漆器在展览著录上的差别，不主张两者出自同一墓葬。`
  - 后：`同馆两件漆器：一只盒子腹部画着撞钟击磬的场面，这只豆只剩一身龙纹和一个名字。`

6 篇的具体改写方向：

| 器物 | 改写后的讲法 |
| --- | --- |
| 彩漆木雕龙纹盖豆 | 从"豆是什么器"讲到"木头会烂、漆不会"，再引同馆鸳鸯形盒的乐舞图 |
| 素面玉琮 | 从"外方内圆、中间空"的形状讲起，再对照金沙十节玉琮的"多"与这一件的"少" |
| 金箔 | 从"金能锤到透光"讲起，讲它原贴在器物表面、器物朽坏后金留下 |
| 垂鳞纹铜方卣 | 从"屋顶形状的盖"切入，讲两只空环耳如何透露一副不见了的提梁 |
| 析君铜戟 | 从"两个戈头、没有矛刺"讲形制，再落到公元前477年受封的公孙宁 |
| 楚子趠鼎 | 从1974年"电一1号墓"这个工地编号讲起，讲"楚子趠"三个字里的国、爵、名 |

## 三、顺带清掉的全站"编辑腔"

- **`museums.ts`**：20 处摘要改写（去掉 `本站/本页/本批`、`不能把……当作`、`不是……而是`、`照录` 等），事实一律保留。
- **故事展示组件**：`哪些已经知道，哪些还需留白` → `考订`；`看懂三个细节` → `三处细节`；`下面讲的是馆藏资料，不是对本站AI画面的鉴定` → `以下依据馆藏与考古资料`；`先用自己的话说一句，不评分，也不必背答案` → `先自己想一想，再点开看看`；`查看高清全卷候选（尚未接入本站）` → `（尚未接入）`。
- **`stories.json`** 的 9 条关联文案重写，例如：
  - 前：`……比较文字怎样记录愿望与音高，不把清宫仪式与曾国礼乐说成直接传承。`
  - 后：`一只清宫金杯写的是吉语，一套曾国编钟写的是音高——同样刻着字，一个记愿望，一个记声音。`

## 四、防回潮机制（本轮新建）

1. `scripts/prose-report.mjs`：随时输出各批次的硬禁用词密度与最密集篇目（`node scripts/prose-report.mjs`）。
2. `scripts/prose-style.test.mjs`（5 项断言）：
   - **只降不升的总额上限**（本轮已把 `本页/本站` 从 420 收到 394 等）；
   - **已改写文件必须 0 标记**（`REWRITTEN` 清单，现为 batch69/70）；
   - 已改写文件的正文不得出现 `本页/本站/读者`，开场不得以"展签上只有……"起句；
   - 关联文案不得出现免责声明腔；
   - `museums.ts` 与 `App.tsx` 同步受控。
3. `docs/audits/2026-10-01-prose-style-guide.md`：风格指南（禁用表 + 可用手法 + 前后示例）。
4. 测试口径同步：把 25 处"必须出现『比较…不主张』"的旧断言整体放宽（现在只要求关联文案有实质长度，不再强制公式句）。
