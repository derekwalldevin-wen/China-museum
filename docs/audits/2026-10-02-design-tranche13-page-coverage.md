# 设计品质第十三轮：把自检覆盖面从 2 个页面扩到 4 个

日期：2026-10-02。这一轮没有改产品，改的是**尺子的覆盖面**——因为评奖看的是整站，而此前的自检只量首页与故事阅读页。

## 一、缺口：故事目录页与访客记录页从未被量过

新增覆盖：

| 页面 | 入口 | 此前 | 现在 |
| --- | --- | --- | --- |
| 首页 | `/` | ✓ 已覆盖 | ✓ |
| 故事阅读页 | `?guide=1&story=<id>` | ✓ 已覆盖 | ✓ |
| **故事目录页** | `?guide=1` | ✗ **未覆盖** | ✓ |
| **访客记录页** | `visitor-records/` | ✗ **未覆盖** | ✓ |

每页在**桌面 1440 与 390** 两个视口各测一遍，判据：唯一 `h1`、390 无横向溢出、无 <12px 文本。

## 二、结果：两页本来就健康（这轮是"验证"）

| 检查 | 故事目录页 | 访客记录页 |
| --- | --- | --- |
| `h1` 数量 | 1 ✓ | 1 ✓ |
| 390 横向溢出 | 0px ✓ | 0px ✓ |
| <12px 文本 | 0 处（桌面/390）✓ | 0 处（桌面/390）✓ |
| `:focus-visible` | 有 ✓ | 有 ✓ |
| 不合格触控目标 | 0 ✓ | 0 ✓ |

访客页的字号是 `rem` 派生的分数值（12.48 / 13.12 / 14.08…），换算后都 ≥12px ✓；它用的是**独立 MPA 入口**，样式自成一套。

## 三、踩到的一个坑：独立入口不能复用主页的挂载判定

第一次跑就超时在"应用外壳挂载"——因为 `goto()` 等的是 `.atlas-shell`，而**访客页根本没有这个外壳**（它是 `visitor-records/index.html` 独立入口，根节点是另一套）。改成"各自判定挂载 + 等自己的目标内容"后才通。

顺带修了第二处：新循环跑完把页面停在访客页，导致随后的**像素级对比度**测不到元素（全是 `n/a`）→ 循环后补一次回首页导航。
