# 文案风格指南（去 AI 腔 · 文学化）

适用：`src/data/stories-*.json`（故事）、`src/data/museums.ts`（馆藏与简介）、`src/App.tsx` 与 `src/components/*` 中面向读者的文案。

## 一、总原则

1. **把有据的细节写活**：铭文、尺寸、纹饰、出土情形、年代背景、修复与流转，都是真实的——用画面感、节奏与悬念讲出来。**不虚构场景、不写对话、不编人物心理**。
2. **不确定就不写**：不要在正文里解释"我不知道"。缺项直接省略；确需说明时，只在末尾「考订」一处用一句平实事实交代（如「展签未标年代，此处不标」）。
3. **写给想看下去的人**：每篇开头三句之内要给出一件具体的东西或一个悬念，不要用"展签上只有两行""本页只记录"这类自我说明开场。

## 二、硬禁用（lint 会拦）

| 禁用 | 原因 | 换成 |
| --- | --- | --- |
| `不是……而是……`／`并非……而是……` | 最典型的 AI 转折腔 | 直接陈述后半句 |
| `不能把……当作`／`不能让……说成` | 说教式否定 | 直接写事实 |
| `本页`／`本站`／`本文`／`本条目`／`本批` | 自我指涉 | 删掉主语，或写"这里" |
| `来源边界`／`分寸`／`收录理由`／`写作纪律` | 编辑口气泄漏到正文 | 删 |
| `值得注意的是`／`需要说明的是`／`这提醒我们` | 模板过渡句 | 删，直接接事实 |
| `比较的是……不主张……` | 关联条目的公式腔 | 用一句人话写清两件器物的差别 |
| `按原文`／`照录`／`不代填`／`不替……` | 考据腔 | 直接给出原文即可 |
| `【器物事实】【器形与年代】` 等方括号标签 | 一眼机器排版 | 删标签 |
| `读者` | 说教距离 | 用"你"或省略 |

## 三、写作手法（可用）

- **从一个实物细节切入**：一件鼎的底部有烟炱、一只壶的盖顶刻着 7 个字、一支戟的两个戈头。
- **给数字与专名**：年代、尺寸、出土年份、墓号、铭文字数——具体就是可信。
- **短句推进**：长解释句拆成两三个短句，段落之间留一个"那么……"的悬点。
- **让器物与人对上**：铸造它的人、使用它的人、埋下它的人、挖出它的人。
- **结尾留钩**：一句能引向下一页的话，而不是总结。
- **考订区（`uncertainty`／`correction`）**：各一到两句，只写事实（"展签未标年代"／"本批新增条目"）。

## 四、改写示例

**例 1 · 开场**

- 前：`【器物事实】这块展厅说明牌只有两行：中文器名「彩漆木雕龙纹盖豆」，英文名「Painted lacquer lidded dou-bowl carved with dragons」。没有时代、没有出土地。`
- 后：`一只豆，盖顶雕着龙，通身漆色发暗。牌子只写了它的名字——彩漆木雕龙纹盖豆。名字里的四个字，恰好把它的样子说完了：彩漆、带盖、豆形、雕龙。`

**例 2 · 不确定**

- 前：`本轮来源仅为展厅说明牌照片，非馆方逐件藏品著录；该盖豆的时代、出土地、尺寸均未取得；……本页不作推断。`
- 后：`展签未标年代与出土地，这里也不标。`

**例 3 · 关联条目**

- 前：`与同在湖北省博物馆的彩漆木雕鸳鸯形盒比较"两件漆器的著录详略"：……比较的是同馆漆器在展览著录上的差别，不主张两者出自同一墓葬。`
- 后：`同样是漆器，鸳鸯形盒上画着撞钟击磬的场面，这只豆只剩下一身龙纹和三个字的名字。`

## 五、执行与验收

- `node scripts/prose-report.mjs`：随时查看各篇的标记密度与最密集的篇目。
- `node --test scripts/prose-style.test.mjs`：硬禁用词 lint，含**只降不升**的总额上限与"已改写文件必须为 0"的清单。
- 每批改写后：`npm run generate:data` → `npm run build` → 全量测试 → 桌面/390 E2E → 发布 → 线上核验。
