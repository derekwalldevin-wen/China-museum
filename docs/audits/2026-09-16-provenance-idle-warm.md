# 当前馆图片溯源元数据空闲预热审计

日期：2026-09-16  
生产站：https://huaxia-museum-atlas.pages.dev/  
不可变部署：https://72b04eb5.huaxia-museum-atlas.pages.dev/

## 实施结果

- 馆内前两张卡片必须完成并具有有效像素后，才进入空闲调度；DOM 仅挂载不算完成。
- 普通网络空闲阶段只复用当前馆 `image-provenance/{museum}.json` Promise 缓存，不调用详情图片预载器。
- Save-Data、`slow-2g/2g` 和已知电量不高于 20% 且未充电时禁止空闲预热，继续只由 focus、pointer 或 touch 意图加载。
- 切馆/卸载会取消尚未执行的 idle callback；已发出的共享请求不强制中断。同馆文物共用一份缓存，失败 Promise 会被删除，后续意图可真实重试。
- 390×844 首屏保持 2 张卡片、37,140 B；空闲阶段详情图片请求为 0，新增网络仅为当前馆故宫 payload 3,048 B。

## 剩余风险

- Battery Status API 并非所有浏览器提供；无法读取时只能依赖 Save-Data 和网络类型，不推断用户电量。
- `requestIdleCallback` 缺失时使用 350 ms 低优先级兼容回退；当前 Edge 验收走原生 idle callback。
- 已开始的 fetch 不强制取消，以保留同馆共享缓存并避免竞态；切馆只保证取消尚未开始的任务。
- 正常网图片可见仍主要取决于 CDN 与图片下载，需用多次样本或真实用户监测才能判断分位数变化。
