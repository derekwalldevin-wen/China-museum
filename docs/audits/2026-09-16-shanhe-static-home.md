# 「山河入画·循迹寻珍」静态首页验收

日期：2026-09-16  
范围：桌面与390px静态首页；不发布线上，不实现新2.8秒开场。

## 实际交付

- 以原创CSS和内联SVG重绘水墨远山、中景山脊、云气、亭台、松影、前景洲岸和纸面层次。
- 保留真实中国省界作为画面中心，以低饱和矿物色区分省域；原有34个省级区域、港澳引线、朱印、标签、坐标和点击逻辑不变。
- 顶部改为题签式指挥栏：品牌朱印、九州名录、故事游线、检索、全国统计、年代与门类筛选形成清晰层级。
- 新增《清明上河图》故事引路笺，把“地域找馆”与“故事寻珍”并列为两条探索入口。
- 390px使用独立构图：紧凑导航、44px筛选控件、放大舆图、留白题字、底部故事入口；无横向溢出。
- 旧“一纸启封”开场暂停触发，且不进入本轮构建；待静态视觉确认后，再以同一组山水层次实现连续2.8秒开场。

## 原创与边界

- 未使用或描摹《三国志11》截图、UI图块、徽记、字体或音画素材。
- 新视觉只借鉴“水墨山河、题签面板、战略探索氛围”这些抽象方向。
- 未修改191件文物数据、20件故事内容、图像选择、AI标识、授权、隔离与溯源处理链。
- 未修改组合筛选、URL恢复、浏览器历史、详情返回位置、地图精度分级和馆内图片调度。
- 未新增图片、字体、模型或运行时网络依赖。
