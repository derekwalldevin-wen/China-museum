# 第六批样板故事核读与本地验收（2026-09-26）

本批新增4篇独立故事：河南博物院贾湖骨笛、武则天金简、莲鹤方壶，上海博物馆《上虞帖》。每件4章、3处细节、亲子思考题和2条带比较理由的关联；四篇正文合计3125字。项目现为40/201件完整故事、113条文字证据，六条原游线的20站不变。修改限于文字、轻题签、馆藏摘要、故事数据和测试；`images.json`及卡片图/详情图、AI标签、授权和处理链未动。
