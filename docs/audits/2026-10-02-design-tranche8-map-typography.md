# 设计品质第八轮：地图标注排版——把"只看 CSS 字号"的错误尺子换掉

日期：2026-10-02。这一轮做当初刻意留给地图专项的那 10 处 7–11px 标注。过程中又推翻了自己的一个判断。

## 一、先踩坑：SVG 里的 `font-size` 不等于屏幕上的大小

我最初按 CSS 字号数出"81 个标注里 74 个 <12px"，差点直接开改。**先量了屏幕实际尺寸才发现事情不一样**：地图 SVG 随视口缩放，CSS 字号要乘上缩放系数才有意义。

| 标注 | CSS 字号 | 屏幕实际高 | **有效尺寸** |
| --- | --- | --- | --- |
| 桌面·省简称 | 11px | 17px | **14.8px** ✓ 本来就好 |
| 桌面·省份件数 | 7px | 8px | **7px** ✗ 真的太小 |
| **手机·省简称** | **9px** | **5px** | **4.4px** ✗✗ 完全读不了 |

手机端地图被缩到约 **0.49 倍**，所以 9px 的省名在屏幕上只有 4.4px —— 这是本轮真正的可读性缺陷，而"桌面 11px 标注"其实一直是达标的。**如果按 CSS 字号盲改，就会把本来好的地方改坏。**

## 二、改法：按缩放系数补偿，字号与印章底板一起放大

| 位置 | 改前 | 改后 | 有效尺寸 |
| --- | --- | --- | --- |
| 手机·省简称 | CSS 9px（有效 4.4px） | **CSS 20px** | **10.4px** ✓ |
| 桌面·省份件数 | CSS 7px（有效 7px） | **CSS 12px** | **11.3px** ✓ |
| 手机·印章底板 | 17×17（**字已溢出底板**） | **26×26** | 字落回底板内 |

第二处修改很关键：我把手机字号调大后截图发现东部一片杂乱 —— 原因是**印章底板还是 17×17**，20px 的字溢出底板，看起来就成了散字。底板同步放大后，密集处读起来是"印群"而不是"字挤在一起"。

## 三、量表升到 v6：加"地图标注"维度

新增维度按**有效显示尺寸**判定（用 `rect.height ÷ (fontSize × 1.15)` 反推缩放系数）：

- 手机省简称有效 ≥10px（4 分中的 2 分）
- 桌面省简称有效 ≥10px（1 分）
- 桌面省份件数有效 ≥10px（1 分）

换句话说：**尺子本身修好了**——原来那套"只量 CSS 字号"的判据会误导人（把达标的桌面标注判成违规，又完全看不出手机上的灾难）。

## 四、诚实说明：东部仍然偏密

手机端标签重叠对从 0 增到 2，东部（鲁苏浙皖闽沪）看着仍偏密。可选的下一步：

1. **按密度抽稀**：在手机上只显示博物馆较多或面积较大的省份（需要几何判断）；
2. **分层显示**：先只显示被选中省份及其邻省；
3. 接受现状（每省名字都在自己的印章里，可读）。

我倾向第 1 种，但它属于信息设计决策，需要你点头再动。
