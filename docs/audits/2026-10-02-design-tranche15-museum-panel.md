# 设计品质第十五轮：体检"看文物必经之路"——馆藏面板

日期：2026-10-02。这一轮把**博物馆详情面板**（`?province=&museum=`）纳入体检。它是用户浏览文物的主路径，此前从未被量过。

## 一、量出的问题（桌面 1440 与 390 各一遍）

| 问题 | 实测 | 性质 |
| --- | --- | --- |
| 品牌副标题仍是 **8px** | 桌面 1 处 | ✗ 低于字号下限（我此前只改了媒体查询里那份，漏了基础样式） |
| 顶部英文副题 **8px** | — | ✗ 同上 |
| 「— 将指针移至国土之上 —」 | 对比度 **2.32** | ✗ 说明性文字，未达 AA |
| 「经纬」标签 | 对比度 **4.0** | ✗ 略低于 4.5 |
| 左右竖排题记（「山河作序 · 博物致知」「THE MUSEUM HANDSCROLL」） | 2.32 / 1.95 | 纯装饰 — 不该硬拉对比度 |

## 二、修法：该提的提，该标装饰的标装饰

1. **字号下限**：品牌副标题与英文副题 8px → **12px**（顺带把不透明度调到 0.78/0.80）。
2. **说明性文字**：坐标提示 `efe6cf/30 → /60`、「经纬」`b49a63/65 → /80`、底部操作提示 `efe6cf/45 → /62`。
3. **纯装饰的竖排题记**：标注 `aria-hidden="true"`——它们与地图内容重复、读屏不需要，语义上就该排除在"信息性文字"之外（同时把不透明度略提到 0.45，观感仍在"刻痕"这一档）。

改完后馆藏面板：**桌面与 390 都是 0 处 <12px、0 处低对比，最低对比度 6.05** ✓。

（面板里还剩两处：色块符号 `■` 4.18、大字「北」3.05/3.81 —— 后者按 WCAG 大字号门槛 3.0 已达标，色块是纯标记。）

## 三、量表：把面板纳入"其他页面"维度

在"其他页面"维度内部腾挪（目录页/访客页的 `<12px` 项各由 2 分降为 1 分，腾出 2 分给面板的桌面/390 各 1 分），**维度上限与总分都不变（仍 100 分）**。

## 四、又踩了一次同一个坑（已记入清单）

新加的面板循环把页面停在了面板页，导致随后的**像素级对比度**全部测成 `n/a`——这是本轮第二次同类问题（上一轮是访客页）。两次都是"循环结束后没把页面带回首页"。已在代码里补上回首页导航。
