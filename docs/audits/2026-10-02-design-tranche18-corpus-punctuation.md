# 设计品质第十八轮：把"加严"落到语料——标点卫生 + 永久测试

日期：2026-10-02。上一轮加严的是**排版**（避头尾），这一轮加严的是**语料本身**：218 篇故事的中文标点规范。同时我自己的第一次扫描方法又是错的，一并记下。

## 一、第一次扫描：方法错了

我先按字面扫 `src/data/stories*.json`，结果报出 **55,154 处"直双引号"**——这显然是荒谬的。原因很直白：**那些引号是 JSON 的语法引号**（`"version": 1`），我把"容器"当成了"内容"。

修正方法：**解析 JSON → 只扫字符串值 → 并且只扫含中文的字符串**。重扫：67 个源文件 / 6,824 个中文串 / 约 **33.5 万字**。

## 二、重扫结果：语料非常干净

| 规范项 | 违规 |
| --- | --- |
| 直双引号 `"`（应为 `“ ”`） | **0** |
| 直单引号 `'`（应为 `‘ ’`） | **0** |
| 半角省略点 `...`（应为 `……`） | **0** |
| 汉字之间的半角逗号 / 句号 / 冒号 / 分号 | **0** |
| 贴汉字的半角 `!` `?` | **0** |
| 贴汉字的半角括号 `()` | **4 处**（同一句，源文件 4 次） |

唯一问题是同一句：元代碑记释文「奉训大夫永春县**达(鲁)**……」。已规范为全角「达（鲁）」——**纯标点形式，措辞与事实一字未动**（这句是引文，我改的只是括号宽度）。

## 三、把它钉死：新增永久单元测试

新增 `scripts/corpus-punctuation.test.mjs`，把上面 9 条规范写成断言，并加了一道防呆：**必须扫到 3,000 个以上中文串**才允许通过——否则一旦语料读不到，测试会"空过"。这条测试的价值在于：以后任何人新增故事，只要用了直引号或半角标点，CI 立刻红。

测试结果：**181/181 通过**（原 180 + 新增 1）。

## 四、回归管线

改了源数据就必须重跑生成：`generate-story-data.mjs` → 218 个 payload 重新生成 → 抽查确认 `qz-mbs.json` 里已是「达（鲁）」，且全库无残留半角 `(鲁)` → 构建 → 发布。
