## 二、三件器物与来源

三件都以**展厅说明牌照片**为一手依据（作者现场拍摄，已作为证据图发布到 `/artifact-sources/user-hubei/labels/<id>-label.jpg`），并以**新华社《何以中国｜考古“挖”出的曾国，是个什么国？》**（央视网转载，协助：湖北省博物馆）作背景与互证。

### 1. `hub-hjd` 曾侯谏铜鼎（叶家山2号墓）

- 展签：西周早期；2011年随州叶家山墓地2号墓出土；「本件浅分裆，腹部饰三组兽面纹。器内壁铸有铭文：『曾侯谏作宝彝』」；「兽面分裆鼎流行于商代晚期至西周早期，常成对出现。此类曾侯谏铜鼎在叶家山墓地2号墓、28号墓各出土一对，大小、形制、铭文相同，应为同批铸造，被分置于不同的墓葬之中。」
- 互证：新华社同述「2号墓、28号墓各出土一对曾侯谏分裆鼎……应为同批铸造，被分置于不同的墓葬之中」，并交代叶家山两次发掘共140座曾国墓葬、三位曾侯、65/28/111号墓为核心、111号墓「犺作烈考南公」簋指向南公（南宫适）封国、随枣走廊的地理意义。
- 写作纪律：「应为同批铸造」在展签与报道中均为推断，正文按原文表述，未改写为定论。

### 2. `hub-hjs` 曾侯谏作媿铜肆壶（叶家山28号墓）

- 展签：西周早期；2013年随州叶家山墓地28号墓出土；「盖沿饰龙纹组成的兽面纹，颈部亦为龙纹。出土时，器盖提手、壶颈及圈足，均有一周朱绘纹带。盖内及壶内壁各铸有铭文：『曾侯谏作媿肆壶』」；「『肆壶』可能是陈列于祭祀仪式中的器物。近似于长筒形的贯耳壶是西周早期新出现的器型，在叶家山墓地和一些商周之际的墓葬中发现有类似器型的铜扣木器，说明这种铜壶的原型是木器。」
- 互证：新华社述及28号墓同出曾侯谏盉（三重满花纹饰、兔形钮、牛角形兽面纹、流上攀爬一龙）与龙纹钺，并据此讨论「曾侯谏」的高等级身份。
- 写作纪律：用途（祭祀陈设）与「原型的木器」都保留「可能／推测」限定。

### 3. `hub-hjy` 黄季嬴铜鼎（随州均川熊家老湾）

- 展签：春秋早期；1972年随州均川熊家老湾出土；「本件内壁铸有铭文：『黄季作季嬴宝鼎，其万年子孙永宝用享』。黄国为嬴姓诸侯国，位于今河南省潢川县附近。春秋时期，曾国与黄国关系密切，曾国墓地常出土黄国青铜器，本件可能是黄国女子嫁到曾国的陪嫁品。」
- 互证：新华社述西周晚期至春秋早期在枣阳郭家庙、京山苏家垄等地发现曾国遗存，曾国疆域广大，与《左传》「汉东之国，随为大」相符。
- 写作纪律：把「现象」（曾国墓地常出黄国器物）与「推测」（陪嫁品）分开写，并断言旧式结论句「证明了两国联姻」不得出现（已写入测试）。

## 四、本轮的事故与处理（重要）

**我用 PowerShell 批量替换计数时写坏了 8 个文件**：`.Replace()` 链在 PowerShell 下把 `node:assert/strict` 变成 `hnode:assert/stricth`、`css2?` 变成 `css0?`、`index.html` 的「208件」变成「008件」等。发现方式：测试出现 `Cannot find module ...imaees.json` 与 `SyntaxError: Unexpected identifier 'hnode'`。

处理：
1. `git checkout --` 回滚这 8 个文件（保留真正的作业文件）；
2. 改用**带出现次数校验的 Node 脚本**做替换：每对「旧串→新串」都要求精确匹配预期次数，任一处不符即**整体中止且不写任何文件**；
3. 替换后逐文件 `node --check` 语法校验，再抽查关键值（`index.html` 的 211 件、`bundle-budget` 的 328_000/54_000/170_000/206）。

此后不再用 PowerShell 做源码批量替换，只做「读取/统计」，写文件一律走 Node 脚本或编辑工具。
