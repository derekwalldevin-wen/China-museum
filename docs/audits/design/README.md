# 设计品质自检标准（design-audit · v2）

目标：把"获奖级品质"落成**可复跑、可比较**的量化检查。每次改版后跑一次，分数只允许上升。

```powershell
npm run build
# 起无头浏览器（任意调试端口），然后：
$env:HUAXIA_CDP_ENDPOINT='http://127.0.0.1:11520'
$env:HUAXIA_E2E_URL='https://huaxia-museum-atlas.pages.dev/'   # 或本地 preview 地址
node scripts/design-audit.mjs
```

输出：`docs/audits/design/design-audit.json`（全部原始测量）与 `design-audit.md`（分项清单）。

## v2 评分维度（10 项，满分 100，自设获奖级阈值 85）

| 维度 | 分值 | 判据 |
| --- | --- | --- |
| 中文字排 | 22 | 正文衬线 5 · 行长 30–34 字 5 · 段首缩进 2em 4 · 字号下限 ≥12px 4 · 行高 ≥1.8 2 · 标点宽度调整 2 |
| 字号体系 | 6 | 一页字号种类 ≤10 |
| 对比度 | 12 | 正文 ≥7（AAA）6 · 次要文字 ≥4.5 6 |
| 无障碍 | 12 | 图片 alt 完整 3 · `:focus-visible` 3 · 触控 ≥24×24（内联正文链接按 WCAG 2.5.8 豁免）3 · 标题层级不跳级 3 |
| 移动端 | 8 | 390px 无横向溢出 5 · 移动端字号下限 ≥12px 3 |
| 性能预算 | 8 | 首屏 JS ≤322KB（硬上限 328KB）5 · 图片策略（首图 eager + 列表 lazy）3 |
| **动效与手感** | 16 | 存在滚动驱动动效 6 · 减弱动效偏好下可感知动效为 0 6 · 在用关键帧只动 transform/opacity 4 |
| **交互状态** | 6 | 载入态（`role=status/alert`）2 · 错误态含重试 2 · 空态/说明态 2 |
| **结构层级** | 6 | 唯一 `h1` 3 · `main`/`nav` 地标齐备 3 |
| **键盘可达** | 4 | 章节锚点可键盘跳转 ≥4 个 4 |

判据依据：W3C《中文排版需求》(clreq)、WCAG 2.1 / 2.5.8、以及可感知动效的度量（被 `prefers-reduced-motion` 压到 0.01ms 的动画不算"在动"，但动画名仍在用，故按**时长 >50ms** 判定）。

测量口径上踩过的坑（都已修正）：
- 隐藏层不能计入：故事页打开时地图层仍是 `aria-hidden`/`inert`，原先被算成 76 处字号违规；
- 图片不是"全部 lazy"才好：首图 eager 才是 LCP 正解，判据改为"首图 eager + 列表图 lazy"；
- 关键帧只统计**页面上真正在用的**动画名（Tailwind/shadcn 带进来的未使用关键帧不计）。

## v2 仍覆盖不到的部分（诚实说明）

**100/100 依然 ≠ 获奖级。** 剩下这些是 v3 要补的量表条目：

1. **视觉焦点与层级**：一屏是否只有一个焦点、三级层次（主/副/正文）是否清晰可测。
2. **图像工艺**：主图裁切与观感、放大细节浏览、图注与状态标记（原件／复制件／AI 示意）的一致版式。
3. **真实性能数字**：LCP / CLS / INP 实测（目前只量了包体与图片策略）。
4. **手势连续性**：移动端滑动、返回、横向手势。
5. **一致性 token**：间距是否统一到 4px 基准、圆角/描边/阴影是否 token 化。
6. **地图标注排版**：SVG 地图仍有 7–11px 标注（`.scroll-*` 10 处），牵动地图布局，需要单独视觉 QA 轮次。
7. **键盘全流程**：跳过导航（skip link）、Tab 顺序、`aria-live` 播报。
