# 设计品质自检标准（design-audit）

目标：把"获奖级品质"落成**可复跑、可比较**的量化检查。每次改版后跑一次，分数只允许上升。

```powershell
# 1) 构建并起本地预览（或用线上地址）
npm run build
# 2) 起无头浏览器，然后：
$env:HUAXIA_CDP_ENDPOINT='http://127.0.0.1:11520'
$env:HUAXIA_E2E_URL='https://huaxia-museum-atlas.pages.dev/'   # 或本地 preview 地址
node scripts/design-audit.mjs
```

输出：`docs/audits/design/design-audit.json`（含全部原始测量）与 `design-audit.md`（分项清单）。

## 评分维度（v1，满分 100，自设获奖级阈值 85）

| 维度 | 分值 | 判据 |
| --- | --- | --- |
| 中文字排 | 30 | 正文衬线 6 · 行长 30–34 字 6 · 段首缩进 2em 4 · 字号下限 ≥12px 6 · 行高 ≥1.8 4 · 标点宽度调整 4 |
| 字号体系 | 10 | 一页字号种类 ≤10 |
| 对比度 | 20 | 正文 ≥7（AAA）10 · 次要文字 ≥4.5 10 |
| 无障碍 | 20 | 图片 alt 完整 5 · `:focus-visible` 5 · 触控目标 ≥24×24（内联正文链接按 WCAG 2.5.8 豁免）5 · 标题层级不跳级 5 |
| 移动端 | 10 | 390px 无横向溢出 6 · 移动端字号下限 ≥12px 4 |
| 性能预算 | 10 | 首屏 JS ≤322KB（硬上限 328KB）6 · 图片策略（首图 eager + 列表 lazy）4 |

判据依据：W3C《中文排版需求》(clreq) 与 WCAG 2.1/2.5.8；动效与降级要求见 `prefers-reduced-motion` 兜底（现有 e2e 亦覆盖）。

## v1 覆盖不到的部分（诚实说明）

**100/100 ≠ 获奖级。** v1 只覆盖"排版、字号、对比、基础无障碍、移动溢出、预算"这类可自动量的硬指标。真正决定 Awwwards / Webby / FWA 的还有：

1. **动效与手感**：滚动驱动节奏、进入/退出曲线、200ms 级反馈、`prefers-reduced-motion` 降级后的等价体验。
2. **首屏体验**：开场墨卷的首帧、加载态、CLS/LCP/INP 实测数字。
3. **信息层级与焦点**：一屏一个视觉焦点、3 级层次、留白节奏（4px 基准体系）。
4. **图像工艺**：主图裁切与观感、放大/细节浏览、图注与状态标记（原件／复制件／AI 示意）的一致版式。
5. **状态完整性**：空态、加载态、错误态、成功态四处齐备。
6. **移动手势**：滑动、下拉、返回的连续性。
7. **键盘全流程**：Tab 顺序、跳过导航、`aria-live` 播报。
8. **一致性**：圆角/描边/阴影/颜色 token 化，间距遵循 4px 基准。

这些都是 v2 要补进量表的条目——**在阈值提高之前，先把尺子做准**。
