## 二、逐件证据

### sc-hxz 制盐画像砖 —— 本批最有价值的一处「未定论」
- [川观新闻（四川日报）《东汉制盐画像砖登陆央视〈国家宝藏〉》](https://cbgc.scol.com.cn/news/110118)，`museum-feature`／`full-text`：川博馆藏汉代画像砖有 **196 件**；本件**上世纪 50 年代出土于成都邛崃花牌坊，高 34.5、长 45 厘米**；画面可逐块辨认——井架汲卤（两层木架每层两人、滑轮木桶）、方形卤水容器、**容器与灶房之间一根管道相连**、灶房煮卤，背景山林有人狩猎砍柴。
- **关键**：报道原文写「川博馆藏的这块汉代画像砖上的制盐画面，**尚不能看清楚煮盐燃料究竟是柴火还是天然气**」，随后列出两说——有学者据灶前**半跪**投薪的姿态推测汉代仍用柴薪；邛崃文物局局长何吉民引《华阳国志·蜀志》「取井火煮之，一斛水得五斗盐。家火煮之，得无几也」，认为用天然气「完全有可能」。
- **本页的分寸**：文献（扬雄《蜀王本纪》「临邛有火井一所……井上煮盐」、诸葛亮导气煮盐、常璩记临邛火井）能证明**当时确实用火井煮过盐**，但**不能证明这块砖上画的灶就是火井的灶**——这一层写进了正文与反思题。

### sc-ssj 后蜀残石经 —— 残片证明「文献里记载的东西真的存在过」
- [央视网《国宝知识点 之 四川博物院推荐 后蜀残石经》](https://tv.cctv.cn/2019/01/04/ARTItApIzh6DmVJ9M4jtC8OX190104.shtml)，`museum-feature`／`full-text`：后蜀广政元年（938 年）开刻、历经**近两百年**，共刻 **13 部**经典、**1000 余块**石碑，又称「蜀刻十三经」；蜀相**毋昭裔**主持，张德昭、孙逢吉等手书上石；立于蜀郡最高学府**文翁石室**，并**首次在典籍之外把注释同时刻于石碑之上**；南宋之后不见于著录（舒大刚认为极可能是 1279 年蒙古铁骑入成都所致）；**抗战期间**成都拓宽老南门、拆毁南城墙时发现**数十块**残片，川博藏品即出于此；残片每块**几十厘米大小**，仍可见「经注并行」的镌刻形态与「既有贞观遗风」的楷书；川博拓片上有「东宫书」印章。

### kz-kzsj 明版彩绘孔子圣迹图 —— 是画，不是版刻
- [孔子博物馆官网转载央视新闻客户端](https://www.kzbwg.cn/news/wb/2023-09-28/2707.html)，`museum-feature`／`full-text`：《明版彩绘孔子圣迹图》**共 36 幅**，来自约 500 年前的明代；取材《史记·孔子世家》《孔子家语》《论语》《孟子》等，**其中 33 幅题有相应的文字注解**；画中孔子长须下垂、宽衣博带、身材高大，与《史记》「长九尺有六寸」（约 2.2 米）等文献描述方向一致；画面举例《问礼老聃图》《退修诗书图》《子路问津图》《尼山致祷图》《在齐闻韶图》《学琴师襄图》；同页还列馆内《三圣像》《孔子观欹器图轴》、清仿绘本与日本大正六年朝鲜刻本，说明这是被反复重绘的题材。

## 三、本批自己发现并修掉的一个渲染缺陷

写这一批时我注意到：**第四十六至四十九批的故事正文里混入了 markdown 强调标记 `**`**（共 136 处），而本站故事阅读器是把文本按纯文本渲染的，页面上会直接显示出星号；既有的第四十三至四十五批正文里没有任何这类标记。已用一个一次性脚本把这四个批次文件里的 `**` 全部清除（脚本对每个文件重新 `JSON.parse` 校验），并**新增一项回归测试**：

```js
test('story prose renders as plain text: no markdown emphasis markers leak into the reader', ...)
```

它遍历**全部 158 篇**故事的小结、章节、细节、反思、不确定与修订说明，禁止出现 `**`、`__` 与 markdown 链接语法；第四十九批的定向 E2E 也增加了「渲染后的章节文本不得含 `**`」的断言。这样同类问题无法再悄悄进入页面。
