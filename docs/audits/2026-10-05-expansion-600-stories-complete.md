## 二、路由判断迁入按需目录（可持续方案）

### 问题

`?story=` 的可用性判断原先依赖入口包里的**硬编码 ID 清单**：218 → 343 时入口增加 6,186 B，余量只剩 3,145 B。按 600 件目标继续增长必然超预算。

### 改造

| 位置 | 改动 |
| --- | --- |
| `src/data/story-routes.ts` | 删除 ID 清单与 `storyTeaserIndex`；`?story=` 只做**形态校验**（`/^[a-z0-9-]{2,64}$/`）。是否存在由**按需加载的故事目录**决定 |
| `src/data/story-teaser-hooks.ts` | 由脚本从故事目录**重新生成**（388 条）；该文件随详情/故事块按需加载，**不占入口预算** |
| `src/components/MuseumDetail.tsx` | "读懂这件文物的故事"按钮改读 `storyTeaserHooks`，语义变为"这件有没有故事" |
| `scripts/stories.test.mjs` | 清单覆盖测试改为"目录中每篇都能按 URL 路由且都有 hook"；无效 ID 契约更新为：**形态合法但不存在 → 进入阅卷台并显示"这一页暂时未能载入"**；形态非法（含 `/`、空格、`..`）→ 直接忽略 |

### 效果（实测）

| 指标 | 改造前 | 改造后 |
| --- | --- | --- |
| 入口静态 JS | 324,855 B（余量 3,145） | **320,980 B（余量 7,020）** |
| 新增 45 篇故事的入口成本 | — | **0 B**（实测入口字节完全未变） |
| hooks 清单位置 | — | 延迟块（实测不在入口 chunk）✓ |
