## 二、这一轮暴露的一个真实风险（已修正）

改写到来源段落时，我**凭记忆重建了几条 source 的 URL/标题**（例如把粤博藏品页写成另一个地址）。这是不能接受的做法——URL 是证据链的一部分。发现后立刻从 git 恢复：脚本按 source id 从 `HEAD` 取回 `title / institution / url / checkedAt / retrieval / kind`，只保留我重写的 `supports` 说明。测试里那条“所有来源必须是 https”的断言正好把它拦了出来。
