# 文物图像逐件证据核验（第五轮）

核对日期：2026-09-23。范围为 D 级 148 条、C 级 35 条；无线上发布、无图像替换。

## 结论

- 对 148 条 D 级记录均以“藏品名 + 当前馆名 + 官方/馆藏”执行逐件检索。逐件查询、当前登记的图像路径与哈希、判定及可引用页面见 `2026-09-23-round5-item-evidence.csv`。12 条带回权威机构/文博部门页面：9 条有支持具体器物匹配的内容，2 条仍需馆藏目录号/名称版本消歧，1 条出现馆藏归属冲突；其余 136 条没有形成可审计的单件权威 URL，保留空 URL 和待核结论。检索不到不等于藏品不存在，也不证明 AI 示意图形状与原件一致。
- 12 个权威页面只用于核对藏品名称、馆藏或器物事实，不代表图像许可；所有 D 级图像仍是 AI/待核，不替换。
- 发现 `yn-dwy`“滇王之印”归属冲突：当前数据标为云南省博物馆，但本轮政府来源称现藏中国国家博物馆。数据未擅自修改，需后续核对馆藏与展出/原藏关系。
- C 级 35 条均保留原图。35/35 本地文件 SHA-256 与 `images.json` 当前 `assetSha256` 一致；但这只证明当前部署文件与本地登记值一致，不是来源原件哈希。0/35 有原件 SHA-256，0/35 有闭合的“来源原件→具体处理→当前派生文件”密码学链；35/35 授权仍为 pending。
- C 级现存登记中有 30 条来源 URL、28 条许可标签、35 条本地哈希。34 条处理注记明确标注历史缩略图的裁切/压缩/下载链待复核；另 1 条《清明上河图》说明已分段并缩放，但缺来源原件哈希、授权与可校验的分片输入清单。源文件和许可页面并非在本轮全部重新下载/逐页复核，逐条标记于证据表，不能视为重新授权或确权。

## 证据边界与待核

即使 Commons 页面列出 CC/PD 许可，也只说明该页面对相应上传文件声明了许可，不自动证明图像拍摄对象与本条藏品版本相同，也不自动证明网站本地 JPEG 就是该原图的可追溯派生。因此本轮不提升 35 条 C 为已授权，不填写推测的原件哈希，不替换图片。`sourceLicense` 保留现有登记标签以便逐条复查；`licensePageReopenedThisRound=false` 明示本轮未把每一个来源许可页重新逐页确认。
