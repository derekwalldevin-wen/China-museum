# 191件文物轻索引与按需加载验收 · 2026-09-15

## 结论

生产界面不再静态导入完整 `museums.ts`。首屏使用59馆/191件轻索引；完整文物故事按博物馆拆成59个独立payload，仅在进入该馆或直达该馆文物时加载并缓存。原搜索对文物故事正文的低权重子串检索被保留，全文语料只在首次输入非空查询时请求。

二维卷轴、地图精度分级、全国组合筛选、URL恢复、详情返回位置、20件故事、长卷双图、AI标识、图片隔离和授权字段均未改变。

## 实现与数据安全

- `museums.ts` 仍是唯一权威源；`npm run build` 在编译前确定性生成轻索引、搜索语料和59馆payload。
- 生成报告绑定源文件及所有派生文件SHA-256；测试逐字段核对59馆、191件、顺序、ID和全文规范化结果。
- 所有朝代×类别×省份组合筛选均与权威源结果一致；搜索测试覆盖馆名、城市、文物名、朝代、类别及59段故事正文片段，旧/新分数、总数和排序一致。
- 直达URL先用轻索引同步确认馆与文物归属，再请求目标馆；手机直达详情实测只下载目标馆，不下载地图几何。
- 馆payload动态模块失败后保留完整URL，通过“保留当前位置，重新载入”可靠恢复；全文语料采用可重试JSON请求，失败时名称/分类基础搜索仍可用。
