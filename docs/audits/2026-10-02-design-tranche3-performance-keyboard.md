## 四、关于"按需引入 GSAP"的结论

目标写的是**按需**，因此本轮明确记录判断：
- 首页开场动效**已在用 Three.js**（`InkScrollIntro`，懒加载，首屏不得含 WebGL 特征由 `bundle-budget.test.mjs` 守住）；
- 故事页的滚动驱动**纯 CSS 已覆盖**（`animation-timeline: scroll()/view()`），零 JS、首屏包体零增长 → **本轮不引入 GSAP**；
- 若后续要做手卷式相机推进或复杂时间轴编排，再引入（GSAP 3.13 起含 ScrollTrigger/SplitText 全部免费可商用），但必须拆成按需分片（首屏余量约 7.3KB）。
