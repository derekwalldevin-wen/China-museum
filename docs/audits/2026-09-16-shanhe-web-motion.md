# 「山河入画」网页动效本地验收

日期：2026-09-16。仅更新本地预览，未部署线上。

## 范围与技术取舍

在已有静态首页上加入2.8秒叙事型墨卷：纸面初展、墨山显影、器物负形与循迹线、朱印落款、真实地图接管。省域、题签、年代签、朱印和故事笺加入短促hover、active、focus反馈。

最初沿用Three.js单平面方案，但软件WebGL冷启动与首帧编译在500ms准备截止下不稳定；复杂shader截图还出现像素纹理和器物双层叠加。最终改为原创内联SVG、CSS与4.31KB按需控制器。没有外部图像、字体、Canvas、Three.js运行块。该选择保留分镜节奏和静态退路，同时把按需块从约510KB/gzip129.5KB降至4.31KB/gzip1.63KB。

用户提供的`derekwen-web-motion` ChatGPT技能页无法公开抓取，本机也没有同名技能，因此没有声称遵循其未读取的具体规则。本轮实际依据已读取的`brainstorming`和`frontend-design`技能，以及用户确认的“叙事型墨卷”强度实施。

## 实测

| 指标 | 结果 |
| --- | ---: |
| 入口JS | 323.14KB / gzip103.17KB |
| 按需开场块 | 4.31KB / gzip1.63KB |
| CSS | 130.40KB / gzip24.93KB |
| 人为延迟冷准备静态回落 | 504.6ms |
| 热路径开场层相对显示就绪 | 47.9ms |
| 热路径地图就绪 | 655.7ms |
| 热路径开场退出 | 3034.1ms（含约183.4ms页面初始化） |
| 桌面跳过 | 42.4ms，动效DOM卸载 |
| 390px馆内首屏 | 2张卡片 / 37,140B |

性能数据：`docs/audits/ink-intro-performance.json`。开场仍仅首次无业务参数的普通导航有资格；分享、筛选、详情、浏览器历史直达均绕过。Save-Data、低速网络、低资源、低电量、减少动态偏好使用静态替代；后者不请求按需动效块。

- 数据、图片溯源、地图精度、故事与包体：62/62。
- 组合筛选、URL、历史、详情返回与披露：25/25。
- 34省与港澳触控：7/7。
- 390px两图、弱网、快速滚动和失败回退：7/7。
