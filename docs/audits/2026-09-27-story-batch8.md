# 第八批故事：简牍、马王堆与三星堆（2026-09-27）

## 范围与结果

前两轮已完成用户优先指定的长信宫灯、曾侯乙编钟、金瓯永固杯、唐三彩载乐骆驼俑、《平复帖》五件既有样板深化，详见同日 `five-sample-story-refinement.md` 与 `five-sample-story-followup.md`；它们不重复计入新增覆盖。本轮继续处理四件尚无完整分层故事的既有藏品：睡虎地秦简《秦律十八种》、辛追墓T形帛画、49克直裾素纱单衣、三星堆青铜大立人。每件新增四章、三细节、一则亲子思考题及两条带具体比较理由的跳转。全馆仍59馆、201件文物，完整故事由44件增至48件，尚缺153件既有藏品及目标约99件新增藏品。新增14条逐件文字来源，累计145条。
