# 设计品质第二十轮：建立动效尺度（28 种时长 → 4 种）

日期：2026-10-02。这一轮转向评审最容易感知、也最难自证的部分——**动效**。做法是先量，再建立尺度，最后**如实记下我自己捅的两个娄子**。

## 一、量出来的问题：没有动效尺度

首页与故事页的样式里共有 **28 种时长取值**，其中大量"近重复"：

```
0.1 / 0.15 / 0.16 / 0.18 / 0.2 / 0.22 / 0.25 / 0.26 / 0.28 / 0.3 / 0.32 / 0.35 /
0.38 / 0.4 / 0.42 / 0.46 / 0.48 / 0.5 / 0.52 / 0.62 / 0.72 / 1 / 1.15 / 1.25 / 1.35 / 1.6 / 2.4 / 2.8
```

`0.42` 与 `0.46`、`0.48` 与 `0.52` 这种差别**没有人能感知**，却让整个界面的"手感"不统一——这是典型的"没有尺度"。

## 二、建立尺度并吸附

在 `:root` 定义唯一事实来源：

| token | 值 | 用途 |
| --- | --- | --- |
| `--motion-instant` | 100ms | 即时反馈：按下、悬停微调 |
| `--motion-fast` | 160ms | 快速：图标、边框 |
| `--motion-base` | 220ms | 基准：面板、卡片 |
| `--motion-slow` | 320ms | 缓慢：抽屉、全屏过渡 |
| `--motion-enter` | 520ms | 进场：章节显现 |

（≥600ms 的是"氛围/开场"时长，不纳入短时长尺度。）

动作：**69 处 CSS 时长吸附** + 两处内联任意值（`.3s`→`.32s`、`.42s`→`.32s`）+ 把 **Tailwind 默认的 `transition`(150ms) 与 `duration-*` 工具类并入尺度**（这段覆盖必须写在 `@layer` 之外，否则优先级低于 utilities 层而失效——第一次就写错在层里）。

### 效果（真实元素的计算值）

| 指标 | 吸附前 | 吸附后 |
| --- | --- | --- |
| 有效时长取值 | 28 种（声明） | **7 种** |
| 其中短时长 | — | **4 种**（0.16 / 0.22 / 0.32 / 0.52） |
| 落在尺度上 | — | **4 / 4 全部** |

## 三、我自己捅的两个娄子（都已修复并留证）

### 娄子一：吸附脚本两次把无障碍开关改坏

`prefers-reduced-motion` 下的"瞬间完成"开关依赖 `0.01ms !important`。我的脚本按"<600ms 就吸附"处理，**两次**把它改成了 100ms——等于在低动态偏好下把动画拉到 100ms，直接违背无障碍保证。

- 两次都立即修回，并**加了硬保护**：`<1ms` 的值一律不动、含 `!important` 的行一律不动；
- 修复后复查：全仓只有 2 处带 `!important` 的时长声明，且都是 `0.01ms` ✓。

### 娄子二：`e2e-intro` 报 "skip took 320–361ms"

先做二分：把这轮改的三个文件还原 → 套件**通过**；说明确实与我的改动相关。但接着做**页面内高精度测量**，真相是：

| 测量方式 | 结果 |
| --- | --- |
| 页面内 rAF 实测（点击→开场卸载） | **18.9ms** |
| 同上，直到内容可交互 | **42.1ms** |
| 原断言（`page.wait` 计时） | 320–361ms |

原因：`page.wait` 是**固定 100ms 轮询**，那个数字 = 真实 19ms + 轮询对齐 + 两次 CDP 往返（机器忙时各约 100ms）。**断言量的是测试框架，不是应用。**

修法：断言改为页面内 rAF 实测，**预算仍是 200ms**（意图未放宽，反而量得更准）。另外按"跳过是无障碍入口"的原则，给跳过路径加了**瞬时退出加固**（退出时直接禁掉本层过渡/动画），使它的延迟不再受任何 CSS 时长影响。修完 `e2e-intro` **连续两次 5/5 通过**。
