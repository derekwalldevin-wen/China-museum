## 关键架构与不要破坏的边界

- `src/data/museums.ts` 是 206 件文物及 59 馆的权威文本源；构建前 `scripts/generate-data.mjs` 派生轻馆索引、按馆完整数据、搜索语料、按件故事目录/载荷、图片安全卡片清单和按馆完整溯源。**不要手工直接改派生 JSON 来代替权威源**。
- 故事分批 `src/data/stories.json`、`stories-batch*.json`；总装在 `src/data/stories.ts`。新增独立故事要同时检查 `story-routes.ts`、`story-teaser-hooks.ts`、测试和 E2E 清单，否则可能出现正文存在但轻 URL 不可达。
- `src/App.tsx` 管全国筛选、URL、异步馆数据/故事加载。故事阅读位置和馆内详情位置使用会话状态；详情返回、刷新、分享链接、前进后退要回归。地图是离线精度分级二维卷轴；省界命中和港澳触控不可改坏。
- `src/data/images.json` 是图片授权/审核权威源；卡片安全清单不等于完整授权数据，详情按馆载入 provenance。隔离图、受限图不可通过回退再次出现，AI 示意与实拍披露必须一致。23 件 `scroll` 展示分类不等于 23 幅均可横向原件阅览；《清明上河图》原件与派生图、双图、分片处理链见历史审计。
- 390px 手机馆内首屏性能边界：**只请求 2 张卡片文物图**；上轮实测总量 27,750 B。不要为了故事或预取额外请求详情图。
- 用户已明确不用 Computer Use；使用本地自动化无头 Edge/CDP。真机低端安卓尚无设备，只能说模拟验收。
